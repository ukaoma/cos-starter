COS Control 0.5.289 (build 342), paired with glasses-server 6.72.0 and complete companion 6.10.639.

Transcription models: Settings has a Transcription card. Pick the live preview model (Whisper Turbo or Parakeet Ultra) and the HQ model for saved meetings, see which engine is actually running and why, and install Parakeet Ultra (about 654 MB, checked file by file, runs offline on the Neural Engine). Preview changes apply to the next live chunk and HQ changes to the next saved meeting; nothing switches in the middle of a meeting. On a server older than 6.72.0 the card is not shown.

Server 6.72.0 also turns on three measured transcription fixes for saved meetings and live audio: timestamped Large-v3 HQ with correct word times, a highpass-only front end, and a speech-detector quiet gate. On silver evaluation through the shipped code, Parakeet Ultra as the live preview had 10.7% fewer errors than Whisper Turbo; Turbo stays the default and Parakeet Ultra is your choice. A second-opinion merge did not clear the bar on the shipped path and is off.
