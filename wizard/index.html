COS Glasses Setup

Get your Even G2 smart glasses running with COS — AI heads-up display powered by Claude Code. Under 5 minutes.

What you need

  • Even G2 smart glasses paired with the Even Realities app
  • Claude Code installed on your Mac — Download here
  • Node.js 18+ — nodejs.org
  • Tailscale (recommended) — connects your Mac and iPhone over a secure mesh network. Download
Why Tailscale? Your glasses app on the phone needs to reach the server on your Mac. Tailscale gives both devices a stable IP address that works from anywhere — no port forwarding, no firewall hassle.

Start the COS Glasses server

Open Terminal on your Mac and run:

$ npx @gotcos/glasses-server click to copy

The server will start and print your connection details:

COS Glasses Server AI heads-up display for Even G2 smart glasses ✓ Node.js 22.1.0 ✓ Claude Code 2.1.90 ↓ Downloading COS Glasses Server... ✓ Downloaded ⟳ Installing dependencies... ✓ Dependencies installed [COS API] HTTP server running on http://127.0.0.1:3141 [COS API] Mode: Standalone (glasses + Claude) [COS API] 🔑 API Token: _AbCd3F... (auto-generated) [COS API] Claude Code CLI detected
Voice commands run locally on your Mac via whisper.cpp — zero per-minute cost. Install once:
brew install whisper-cpp
The launcher auto-downloads the ~3.1 GB Whisper model on first run.

Prefer cloud? Skip the brew install and set OPENAI_API_KEY — the server falls back to OpenAI API ($0.006/min) automatically.

Connect your devices

  • Install Tailscale on your Mac and iPhone
  • Sign in with the same Google account on both
  • Open Tailscale on your Mac — find your device's IP (starts with 100.)
Already on the same WiFi? You can use your Mac's local IP instead (shown in the server output as "Network"). Tailscale is better for reliability — it works across networks and survives WiFi changes.

Install COS Glasses on Even Hub

  • Open the Even Realities app on your iPhone
  • Go to Even Hub → search for "COS Glasses"
  • Install and open the app

The setup wizard will appear asking for your server IP and API token.

Connect and go

  • Enter your Mac's Tailscale IP (from Step 2)
  • Paste the API token (from the server terminal output)
  • Tap Connect

That's it. Ask anything — your query goes to Claude via your local server, and the response streams to your glasses in real time.

Have a COS username? Tap "I have a COS username" in the wizard and enter it. Your server details will be looked up automatically — no IP or token needed.

Troubleshooting

  • "Cannot reach server" — Make sure both devices are on Tailscale (or same WiFi). Check that the server terminal is still running. As of v5.3.1 the wizard auto-detects unreachable URLs at boot and re-shows the setup screen automatically.
  • "Claude not found" — Install Claude Code: claude.ai/download. Run claude --version to verify.
  • Voice silent or expensive — Run brew install whisper-cpp for free local transcription. Without it, voice falls back to OpenAI API and requires OPENAI_API_KEY. The launcher prints which mode is active on every start.
  • Wrong server URL stuck after Disconnect — Update to v5.3.1 or later. Older builds had a disconnect-loop bug where the URL re-injected from bridge SDK storage on every reload. v5.3.1 stores the logout flag in SDK storage so it survives the WebView wipe.
  • Recover an interrupted meeting — If iOS killed the WebView mid-recording (e.g., long lock-screen background), the transcript chunks are still on the server. Find the orphaned session in ~/.cos-glasses/app/server/data/active-sessions/ and POST the session ID to /api/meeting/save to finalize. The active-meeting handle is also persisted client-side as of v5.3.0 so the next launch surfaces the orphan automatically.
  • Server disconnects — The server auto-reconnects. If persistent, restart with npx @gotcos/glasses-server.

Build from source

Want to customize the server or contribute? Clone the repo directly:

$ git clone https://github.com/ukaoma/cos-glasses-app.git click to copy
$ cd cos-glasses-app && cp .env.example .env && npm install && npm run start:server click to copy

See the GitHub repo for full documentation, configuration options, and LLM provider setup.
