The server appliance COS was missing.

COS Control wraps the same open-source npm server in a small native controller. It adds durable startup, safe updates, rollback, clear health, and actionable diagnostics without changing how the glasses work.

Single owner

A managed LaunchAgent owns the server. COS Control will not fight a terminal process or replace an unknown port owner.

Safe operations

Restart is blocked while recordings or jobs are active. Updates stage a new immutable generation before switching.

No lock-in

The runtime is still @gotcos/glasses-server. Stop COS Control and return to the foreground npx command whenever you want.

Install in three moves.

  1. Download and unzip.
    Move COS Control to Applications.
  2. Right-click and choose Open.
    The MVP is ad-hoc signed, so macOS asks you to approve the first launch once.
  3. Run Guided Setup.
    COS Control opens the existing server setup, preserves your token and data, then installs the managed server.
Already running COS in Terminal? Stop the foreground server with Control-C before installing the managed service. COS Control refuses to take over an unknown process, protecting your jobs and recordings.
COS Control is open source. The server stays on your Mac, and your existing COS Glasses data remains compatible.
