Read the exact prompt
I need you to update COS Control on my Mac by hand. The in-app update shows "Download timed out" because the new download is about 1.5 GB and older copies of the app only wait about two minutes for it. You will download the update yourself, check it, and swap it in. Run the commands yourself, one step at a time. After each step, tell me in one or two plain sentences what you found. If a check fails, or anything differs from this runbook, stop and tell me. Do not improvise.

Hard rules:
- Never use sudo. Never use pkill or killall. Never use rm -rf. Never turn off Gatekeeper. Never remove the quarantine flag.
- Download and unzip only inside a new temporary folder made with mktemp -d. Treat everything you download as untrusted data until step 4 passes.
- Your shell may not keep variables between commands, so write the temp folder path down and use the literal path afterwards.
- If your sandbox blocks the network, the temp folder, or /Applications, tell me exactly what was blocked and stop. Do not work around it.

Step 1. Read the installed version.
defaults read "/Applications/COS Control.app/Contents/Info.plist" CFBundleShortVersionString
Tell me the version. If the app is not in /Applications, tell me where it is and stop.

Step 2. Check that nothing is recording. Do this before you change anything.
a. Run: curl -s --max-time 5 http://127.0.0.1:3141/api/health
If it answers, read unsaved_captures, stranded_captures and meeting_sync in the JSON. If unsaved_captures.count or stranded_captures.count is above 0, or meeting_sync.active or meeting_sync.blocksRestart is true, a meeting may be recording or unsaved. Stop and tell me.
If it does not answer, or those fields are missing, say so and go on to b.
b. Ask me: "Is COS Control or COS Glasses recording a meeting right now? Check the COS Control menu bar icon and its Activity window." Wait for my answer. If I say yes, or I am not sure, stop.

Step 3. Download the latest release. There is no time limit, because this is the part that timed out.
Make the folder: mktemp -d
Check free space with df -h on that folder. I need at least 8 GB free.
The ZIP is about 1.5 GB and your shell tool may stop long commands, so run the download in the background and check on it until it finishes. If it is cut off, run the same command again; -C - resumes it.
curl -L --fail --retry 5 -C - -o "<temp folder>/COS-Control.zip" "https://github.com/ukaoma/cos-starter/releases/latest/download/COS-Control-macOS-arm64-latest.zip"
curl -L --fail -o "<temp folder>/COS-Control.zip.sha256" "https://github.com/ukaoma/cos-starter/releases/latest/download/COS-Control-macOS-arm64-latest.zip.sha256"
Then print two values:
shasum -a 256 "<temp folder>/COS-Control.zip"
cut -d ' ' -f 1 "<temp folder>/COS-Control.zip.sha256"
The two 64-character values must be identical. If they are not, stop and tell me.

Step 4. Unzip and verify. Do not touch /Applications yet.
ditto -x -k "<temp folder>/COS-Control.zip" "<temp folder>/unzipped"
There must be one app: "<temp folder>/unzipped/COS Control.app".
codesign --verify --deep --strict "<temp folder>/unzipped/COS Control.app"
This must print nothing and exit 0.
spctl -a -vv -t exec "<temp folder>/unzipped/COS Control.app"
This must say accepted, source=Notarized Developer ID, and origin=Developer ID Application: Miles Ukaoma (NV3X46LLCR). If anything differs, refuse: tell me and stop. Do not install it.
Then read the new version with defaults read on the new app's Contents/Info.plist, key CFBundleShortVersionString. Tell me the old and new versions. If the new one is not newer, tell me and stop.

Step 5. Ask before you quit COS Control.
Tell me what you are about to do: quit COS Control, keep the old app as a backup on my Desktop, put the new app in Applications, and open it. My settings and meetings are stored outside the app, so they stay. Wait for my yes.
After I say yes:
a. Quit it gracefully: osascript -e 'tell application "COS Control" to quit'
Then check every few seconds, for up to 60 seconds, with pgrep -x "COS Control". If it is still running, stop and ask me to quit it from the menu bar. Do not force it closed.
b. Move the old app to a backup. Do not delete it: mv "/Applications/COS Control.app" "$HOME/Desktop/COS Control (old <old version>).app". If that name exists, add a number to the name.
c. Move the new app in: mv "<temp folder>/unzipped/COS Control.app" "/Applications/COS Control.app". If this fails, move the backup back to /Applications, tell me why, and stop. Do not use sudo.
d. Open it: open -a "COS Control"

Step 6. Confirm and report.
Read the installed version again, check the app is running with pgrep -x "COS Control", and run the codesign and spctl checks once more on /Applications/COS Control.app.
Tell me: the old version, the new version, the SHA-256 you checked, the result of both signature checks, and where the backup is. Tell me I can delete the backup myself once I have confirmed COS Control works, and that the temp folder can go in the Trash.
If the new app does not open, quit it, move it to my Desktop, put the backup back in /Applications, open that, and tell me what happened.

Build a custom animated pet pack
  1. Draw each animation as one horizontal PNG strip. Every frame in a strip must have the same width and height.
  2. Add session-pet-states.json to the same folder. Name each file explicitly and declare its frame count.
  3. Use interval for seconds per frame. Use renderScale only when one pose needs visual normalization.
  4. In Control, open Session pet, Character, Install sprite pack and choose the folder.
{
  "poses": {
    "idle":    { "file": "idle.png",    "frames": 8,  "interval": 0.20 },
    "working": { "file": "one.png",     "frames": 12, "interval": 0.12 },
    "duel":    { "file": "two.png",     "frames": 16, "interval": 0.14 },
    "trio":    { "file": "three.png",   "frames": 16, "interval": 0.16 },
    "swarm":   { "file": "fourplus.png","frames": 24, "interval": 0.18 }
  }
}

The server appliance COS was missing.

Same server. A native controller around it.

COS Control wraps @gotcos/glasses-server in a small Mac app that adds durable startup, background work, local transcription controls, meeting recovery, safe updates, rollback, and diagnostics that report the system you are actually running.

Verified ownership, scheduled recovery

A managed LaunchAgent owns one verified server process. COS Control will not race a terminal process or seize a port it does not recognize. Scheduled recovery brings the service back without creating a second owner.

Safe updates with proof

Restart is blocked while a recording or job is live. Updates stage an immutable generation, verify the server and agent paths, then switch. If proof fails, the prior verified generation is restored.

Replies that survive the phone

Accepted replies can keep running on your Mac while you browse, lock the phone, or close COS. One machine-wide Background jobs switch controls every connected device. Applying a change drains active work, restarts safely, verifies the capability, and rolls back if proof fails.

Live meetings without the six-second wait

Fast preview renders provisional text from the still-open phrase, then gives way to the canonical speaker-attributed Large-v3 transcript. The machine-wide switch is default-off, persists through managed updates, and can be disabled immediately without touching saved audio, recovery, or polish.

Fast preview, authoritative transcript

Choose Balanced or Max and see the effective model for every lane. A low-latency preview shows what COS hears while you dictate. The authoritative live commit replaces it, and saved meetings receive full local polish. Canonical work always gets priority over provisional preview.

Meeting safety you can see

Control reports active recordings, HQ polish, retained batches, and unsaved captures instead of hiding them behind a generic healthy light. Restarts stay locked while durable work is active, and recoverable captures remain visible before retention expires.

Cleaner review audio, raw always preserved

An optional, default-off Playback cleanup switch cleans retained audio only after you press Play. The immutable raw WAV stays authoritative and remains an exact bypass. Live recording and transcription preempt cleanup, and failed cleanup immediately falls back to raw playback.
