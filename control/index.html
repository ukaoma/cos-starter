The server appliance COS was missing.

Same server. A native controller around it.

COS Control wraps @gotcos/glasses-server in a small Mac app that adds durable startup, safe updates, rollback, clear health, and real diagnostics, without changing how the glasses work.

One owner, no fights

A managed LaunchAgent owns the server. COS Control will not race a terminal process or seize a port it does not recognize.

Safe by default

Restart is blocked while a recording or job is live. Updates stage a new immutable generation, then switch, so a bad update rolls back clean.

No lock-in

The runtime is the same @gotcos/glasses-server. Already run your own? COS Control can manage it in place, with no reinstall and no re-pairing. Quit any time and go back to the plain npx command.

Work Folder

Under Tools, Work Folder is your COS project root — the workspace Claude, Codex, and Cursor search and edit. It does not move the managed server package. Each person’s COS can live anywhere; pick the folder that matches yours. Managed servers reload safely; older adopted servers show the selection as pending until a safe restart is available.

Meetings Library

Meetings Library is separate. Point it at your COS operations/ tree (the folder that contains quilt/meetings, personal/meetings, and the rest) so G2 Review Meetings reads your real meeting markdown. Leave it unset for standalone local recordings only. Different COS layouts are expected — set the path that fits your machine.

Today's glasses turns, one copy away

Recent Glasses lists the last 30 turns from today and copies a paste-ready handoff into any chat, so you can pick up a thread on the Mac without a recall command. Messages are read from your own local server and never leave the machine.

Your speed / quality choice

Guided Setup offers Balanced or Max. Balanced keeps Small.en prompt previews fast while Turbo commits the authoritative live transcript. Max uses Turbo for low-latency provisional preview while Large-v3 remains authoritative for commit and polish. Canonical transcription always gets priority. Control applies the choice transactionally, reports the model actually running, and restores the prior tier if verification fails.

Real CLI versions

The Agent CLIs caption shows Claude, Codex, and Cursor versions for support. Cursor's build comes from Control's local probe even when server health only says “About Cursor CLI.”

Install in four moves.

Download, approve once, guided setup, point your folders.

  1. 1

    Download and unzip.

    Move COS Control into your Applications folder.

  2. 2

    Approve the first launch.

    COS Control is open source but not notarized yet, so macOS flags it as an unidentified developer. Clear the download flag once in Terminal, then open it normally: xattr -dr com.apple.quarantine "/Applications/COS Control.app" Prefer clicks? Open the app, then in System Settings under Privacy & Security click Open Anyway.

  3. 3

    Run Guided Setup.

    Choose Balanced (recommended) or Max. COS Control checks whisper.cpp, verifies free disk space, and provisions the selected local models without interrupting the running server. When it finishes, Install or Update Server if offered, then Apply the tier for a verified restart. Then use the setup wizard profile step to add names and specialist terms; factory placeholders are ignored.

  4. 4

    Point COS at your folders.

    In the menu-bar panel under Tools: set Work Folder to your COS project (agent workspace), and set Meetings Library to that project’s operations/ folder if you use COS meeting markdown on G2. Paths differ per install — pick what matches your machine.

“Apple could not verify” on first open? Expected, and safe. COS Control is not notarized yet, so macOS treats it as an unidentified developer. The step 2 command (or System Settings, Privacy & Security, Open Anyway) clears it in one move. Notarization is on the way.
What you need. macOS 14 or later on Apple Silicon, Node.js 20.11 or later, whisper.cpp plus about 6 GB free for adaptive local transcription, and at least one harness: Claude Code, Codex CLI, or Cursor Agent (agent). One harness is enough. Doctor checks all three and tells you which are ready.
Already running COS in Terminal? Stop the foreground server with Control-C before installing the managed service. COS Control refuses to take over a process it does not own, so your jobs and recordings stay safe.
